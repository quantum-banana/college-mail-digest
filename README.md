# College Mail Digest Metadata

Public informational pages for a personal college email assistant.

- Homepage: https://quantum-banana.github.io/college-mail-digest/
- Privacy Policy: https://quantum-banana.github.io/college-mail-digest/privacy.html
- Terms of Service: https://quantum-banana.github.io/college-mail-digest/terms.html

This repository contains only static website content. It does not contain
the assistant implementation, Gmail messages, credentials, private state or
reports. This website does not request Gmail access.

GitHub Pages publishing source: `main`, repository root. No build tooling,
third-party JavaScript, external fonts or package installation is needed.
The `.nojekyll` file serves the static files directly.
