HOW IT WORKS

A clear view of the information that matters.

01

Read selected mail

The assistant uses gmail.readonly to read message metadata and selected inline text. Each run follows the owner's instructions.

02

Make useful summaries

OpenAI/Codex processes selected email information to produce summaries, actions and deadlines, with links back to original messages.

03

Keep access protected

The reusable refresh credential is encrypted locally with Windows CurrentUser DPAPI and private file permissions. Access tokens stay in memory.

Reading access, without Gmail writes

The Gmail API helper does not send, delete, archive, label or otherwise modify messages. It does not download attachments. The read-only permission can cover the mailbox, while individual runs are bounded by the owner's request.

Built for one owner's use

This assistant is maintained by quantum-banana for personal college email review. It is not distributed to other users and is not an official VIT service. This website describes the app; it does not connect visitors to Gmail or display mailbox contents.
